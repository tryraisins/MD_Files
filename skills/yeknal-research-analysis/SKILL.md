# Research and analysis

Turn an ambiguous research request into a bounded question, an explicit source contract, and an evidence-backed answer. Match depth to the decision.

## Choose the depth

- **Ordinary research:** use the workflow below and stop once the decision can be supported honestly.
- **Deep research:** when the user explicitly asks for deep, exhaustive, or claim-verified research, read [references/deep-research.md](references/deep-research.md). It adds resumable evidence ledgers, independent claim checks, saturation-based stopping, and evidence-only follow-up without creating a competing skill.
- **Simple lookup:** answer from the best current source. Do not build a research workspace or run multiple rounds when one verified source settles the question.

## Choose the lens

- **Data research:** find datasets, inspect their provenance, define fields and quality limits, validate transforms, and separate observed values from inference.
- **Market research:** define audience, geography, segment, alternatives, pricing, adoption signals, and uncertainty; never treat marketing claims as market size.
- **Competitive intelligence:** compare named alternatives on the dimensions the user cares about, cite primary evidence, and separate feature facts from interpretation.
- **Trend analysis:** time-bound the signal, compare multiple independent sources, name drivers and counter-signals, and label forecasts as forecasts.
- **Search and discovery:** start with precise queries, refine with domain and date filters, prioritize primary sources, and record the exact page or dataset used.
- **Research analysis:** synthesize themes, contradictions, confidence, implications, and next actions without hiding missing evidence.

## Workflow

1. Restate the question and define what a useful answer would contain.
2. Set freshness, geography, audience, and source-quality requirements.
3. Gather primary sources first; use secondary sources only for context and triangulation.
4. Extract only decision-relevant facts and preserve links, dates, and units.
5. Compare evidence, resolve contradictions, and label inference or uncertainty.
6. Deliver a concise synthesis with findings, caveats, and recommended next steps.

Scale the report to the requested output. "Deep" raises evidence rigor and coverage, not permission to pad length.

## Integrity rules

- Never invent sources, quotations, statistics, or current facts.
- Do not extrapolate a trend from a single anecdote or one provider's marketing page.
- State when information is stale, unavailable, self-reported, or inferred.
- For high-stakes, current, or user-requested lookups, browse and cite the supporting sources.
